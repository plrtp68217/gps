# Имитационная модель планировщика GPS

## Описание
Данная программа реализует имитационную модель планировщика GPS (Generalized Processor Sharing). Она предназначена для моделирования работы планировщика с несколькими потоками (очередями), учитывая приоритеты, случайное распределение времени прихода пакетов и длину пакетов.

## Исходные данные
Программа принимает следующие входные данные:
- **Количество потоков (очередей)**: N
- **Приоритеты для каждого потока**: массив приоритетов, где каждый элемент соответствует приоритету потока.

Далее формируются следующие входные данные:
- **Случайное распределение времени прихода пакетов**: время прихода пакетов каждой очереди генерируется с использованием экспоненциального распределения.
- **Случайная длина пакетов**: длина пакетов генерируется случайным образом.

## Результаты
После выполнения имитации программа предоставляет результаты в двух форматах:
1. **Графическое представление**: графики, показывающие работу алгоритма GPS для N очередей с различной загрузкой.
2. **Табличное представление**: таблица, содержащая следующие данные:

| Номер потока | Вес пакета | t прихода | t принятия | t обработки |
|--------------|------------|-----------|------------|-------------|
| 1            | 7.04       | 1         | 1          | 19          |
| 1            | 18.38      | 3         | 19         | 65          |
| 1            | 8.88       | 3         | 65         | 88          |
| ...          | ...        | ...       | ...        | ...         |

1. Установить Python 3.x.
2. Склонировать репозиторий:

    git clone <URL_репозитория>
3. Установить необходимые библиотеки из файла requirements.txt:
   ```bash
   pip install -r requirements.txt
4. Перейти в директорию проекта:
   ```bash
   cd <имя_директории>

## Запуск
1. Для запуска программы выполните следующую команду:
    ```bash
    python gps_simulation.

## Использование
При запуске программы вам будет предложено ввести количество потоков, их приоритеты в следующем виде:

[[n1, n2], [w1, w2]

Где n1 - номер 1 потока,w1 - приоритет 1 потока.

Пример: [[1, 2], [2, 3]]

После ввода данных программа выполнит имитацию и отобразит результаты.
