Имитационная модель планировщика GPS
Описание программы
Программа представляет собой имитационную модель планировщика GPS (Generalized Processor Sharing), которая позволяет моделировать работу алгоритма с различными параметрами и анализировать его поведение. Основная цель — визуализация и анализ результатов работы алгоритма для различных конфигураций очередей и их загрузки.

Исходные данные
Для работы модели используются следующие исходные данные:

Количество потоков (очередей): Количество очередей, входящих в планировщик.

Приоритеты для каждого потока: Устанавливаются приоритеты для каждой очереди.

Случайное распределение времени прихода пакетов: Время прихода пакетов для каждой очереди генерируется с использованием экспоненциального распределения.

Случайная длина пакетов: Длина пакетов также генерируется случайным образом.

Степень загруженности каждой очереди: Указывается загруженность каждой очереди.

Результаты
Программа предоставляет следующие результаты:

1. Графики
Графики, отображающие результаты работы алгоритма GPS для заданного количества очередей и их загрузки.

Графики позволяют наглядно увидеть количественные характеристики для каждого потока.

2. Таблица
В табличном виде представлены следующие данные для каждого потока:

Поток №: Номер потока.

№ пакета: Номер пакета в потоке.

Случайное число (экспоненциальное распределение): Случайное число, используемое для генерации времени прихода пакета.

Время прихода пакета: Время прихода пакета, сгенерированное с использованием экспоненциального распределения.

Время окончания обслуживания пакета: Время, когда пакет завершил обслуживание.

Цель
Цель программы — предоставить наглядное представление количественных характеристик для каждого потока, чтобы можно было произвести сравнение и увидеть все частные случаи работы алгоритма GPS. Это позволяет анализировать поведение планировщика в различных условиях и принимать обоснованные решения.
